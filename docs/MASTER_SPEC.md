# MASTER SPEC — Nastya Story

## Назначение

Этот файл — карта канонической проектной документации. Он не дублирует детальные спецификации, а указывает, где искать актуальные правила.

## Статус базы

Инфраструктура базы знаний создана. Существующие ранее разработанные ТЗ и контент должны переноситься сюда отдельными контролируемыми этапами с проверкой актуальности; не считать пустые разделы доказательством отсутствия механики в проекте.

## Разделы

### Игровые системы — `docs/systems/`
Здесь фиксируются общие правила, применимые во многих сценах/локациях: время, энергия, питание, характеристики, отношения, инвентарь, гардероб, транспорт, задания, события, обучение и т. п.

### Мир — `docs/world/`
- `hyperclusters/` — крупные зоны мира;
- `locations/` — конкретные игровые локации;
- `objects/` — интерактивные и описываемые объекты;
- `npcs/` — персонажи;
- `actions/` — доступные действия и их условия;
- `effects/` — временные/постоянные эффекты;
- `quests/` — каноническая структура квестов и целей.

### Контент — `docs/content/`
- `scenes/` — последовательности игровых сцен;
- `dialogues/` — диалоговый контент;
- `descriptions/` — авторский описательный текст и библиотеки вариантов.

### Графы — `docs/graphs/`
Mermaid-графы для визуализации мира, зависимостей, квестов и связей сущностей. Графы являются представлением канонических данных; при расхождении приоритет у карточек сущностей/спецификаций.

### Задания — `docs/tasks/`
Задания для реализации Codex проходят статусы `backlog → ready → in_progress → review → done`.

## Правило обновления

Когда в обсуждении утверждается новая механика или факт мира:
1. определить канонический файл;
2. обновить его;
3. обновить связанные сущности/графы при необходимости;
4. только после этого сформировать TASK для реализации.

## Идентификаторы

Использовать стабильные машинные ID на английском в `snake_case`, например:
- `loc_apartment_5_room`
- `obj_apartment_5_wardrobe`
- `npc_nika`
- `action_take_shower`
- `effect_hungry`
- `quest_2026_08_29_first_day`

После появления ID не менять его только ради красоты имени: стабильность ссылок важнее.
