# Автобусная остановка спального района

## Назначение
Транспортный узел для перемещения между гиперкластерами.

## Взаимодействие
При выборе остановки открывается список доступных направлений. До подтверждения для каждого направления показывается временная стоимость поездки.

Стартовое известное направление:
- университет.

В первой версии доступен только автобус. Архитектура интерфейса/маршрутов не должна запрещать последующее добавление пешего маршрута, такси и других способов.

## 29 августа
Используется для обязательной поездки Насти в университет. Время поездки учитывается при расчёте последнего безопасного отправления до закрытия приёмной комиссии.

## Ещё не определено
Визуальный паспорт остановки, номер/название маршрута, точная длительность поездки и тексты ожидания/поездки.
