# Жилой дом

## Каноническая структура
- два подъезда;
- пять этажей;
- две квартиры на каждом этаже;
- первый подъезд доступен для перемещения по этажам;
- второй подъезд первоначально является заглушкой;
- квартира №5 — Настя и Маша;
- квартира №6 — Ника;
- обе квартиры находятся на третьем этаже первого подъезда;
- на площадке третьего этажа две двери находятся напротив друг друга;
- крыша предусмотрена как будущая локация;
- подвал предусмотрен как закрытая локация, доступ по квестовому ключу.

## Канонические визуальные факты из пролога
- дом новый, но не элитный;
- общий вид аккуратный;
- подъезд чистый;
- в доме есть работающий лифт;
- двор воспринимается как нормальный жилой двор;
- во дворе есть небольшая детская/игровая площадка.

## Визуальный паспорт — ещё требуется разработать
Не утверждены и должны быть определены отдельно:
- материал и цвет фасада;
- точный архитектурный стиль;
- оформление входной группы;
- лестницы, почтовые ящики и освещение;
- конкретный вид лифта;
- двери квартир;
- подробное устройство двора.

Нельзя изображать дом старой запущенной пятиэтажкой или грязным подъездом: это противоречит прологу.
