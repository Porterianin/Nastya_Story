# Локации — карта раздела

Канонические карточки конкретных игровых пространств. Для новой карточки использовать [`../../templates/LOCATION_TEMPLATE.md`](../../templates/LOCATION_TEMPLATE.md).

Основные группы:

- `apartment_building.md`, `entrance_1_floor_3.md` — дом и подъезд;
- `apartment_5.md` и `apartment_5_*` — квартира Насти и Маши и её помещения;
- `apartment_6_hallway.md` — входная карточка квартиры Ники и её внутренние помещения;
- `loc_cafe.md` — кафе;
- `loc_masha_school.md` — школа Маши;
- `loc_bus_stop_residential.md` — остановка спального района.

Физическую структуру сверять с [`../../graphs/residential_district.mmd`](../../graphs/residential_district.mmd), реальные переходы — с [`../../graphs/residential_navigation.mmd`](../../graphs/residential_navigation.mmd). Полная change-impact карта: [`../../REPOSITORY_MAP.md`](../../REPOSITORY_MAP.md).
