# NPC — карта раздела

Системные карточки персонажей: роль в мире, расписание, текущие/связанные локации, игровые функции и связи с квестами.

- [`npc_masha.md`](npc_masha.md) — системная карточка Маши; её личный канон хранится только в [`../characters/masha_canon.md`](../characters/masha_canon.md).
- [`npc_nika.md`](npc_nika.md) — Ника, соседка и фотограф.
- [`npc_aslan.md`](npc_aslan.md) — Аслан, владелец кафе.
- [`npc_olya.md`](npc_olya.md) — Оля, официантка кафе.

Если у персонажа есть отдельная карточка в [`../characters/`](../characters/), здесь не дублируются его внешность, характер, индивидуальная речь, тело и гардероб. Для NPC без отдельного canon-файла индивидуальные постоянные свойства могут храниться в `npc_*.md`. Для новых карточек использовать [`../../templates/NPC_TEMPLATE.md`](../../templates/NPC_TEMPLATE.md).
