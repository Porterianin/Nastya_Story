Крупные зоны мира. Карточка гиперкластера задаёт состав подлокаций, транспортные связи, правила открытия и общий визуальный характер зоны.

- [`residential_district.md`](residential_district.md) — стартовый спальный район.
- [`hc_university.md`](hc_university.md) — университетский гиперкластер.

Физическую структуру и реальные переходы дополнительно отражают производные Mermaid-графы в [`../../graphs/`](../../graphs/). Транспортные правила: [`../../systems/TRANSPORT_SPEC.md`](../../systems/TRANSPORT_SPEC.md).
