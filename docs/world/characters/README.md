# Персонажи — карта раздела

Короткая точка входа в канон центральных персонажей. Для генерации сцены читать только карточки реально участвующих персонажей и необходимые связанные документы.

- [`nastya_canon.md`](nastya_canon.md) — полный индивидуальный канон Насти: биография, характер, поведение, внешность, речь и визуальные ограничения.
- [`masha_canon.md`](masha_canon.md) — полный индивидуальный канон Маши: биография, характер, поведение, внешность, речь и визуальные ограничения.

Общие правила построения диалогов и экранных блоков: [`../../content/DIALOGUE_WRITING_GUIDE.md`](../../content/DIALOGUE_WRITING_GUIDE.md).

Системные роли, расписания и игровые связи NPC: [`../npcs/`](../npcs/).

Правило: индивидуальные свойства персонажа хранятся в его собственной канонической карточке и не определяются через сравнение с другим персонажем.
