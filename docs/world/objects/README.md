# Объекты — карта раздела

Здесь хранятся отдельные карточки интерактивных и значимых предметов мира: внешний вид, состояния, осмотр, доступные действия и прямые связи. Для новых карточек использовать [`../../templates/OBJECT_TEMPLATE.md`](../../templates/OBJECT_TEMPLATE.md).

Отдельных object-карточек пока нет. Не создавать объект только ради упоминания предмета в сцене или локации: отдельная карточка нужна, когда предмет имеет устойчивое состояние, интерактивность или используется несколькими сущностями/сценами.

Карта мира: [`../README.md`](../README.md).
