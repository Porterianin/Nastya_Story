## Ещё НЕ перенесено 1:1

Следующие исходные ТЗ уже существовали до создания GitHub-базы. Их содержание используется как основание проекта, но полные оригинальные файлы пока не скопированы в репозиторий побайтно/1:1:

1. `CHARACTERISTICS_SPEC.md`
2. `RELATIONSHIPS_INVENTORY_WARDROBE_SPEC.md`
3. `TIME_ACTIONS_QUESTS_EVENTS_SPEC.md`
4. `UI_VISUAL_SYSTEM_SPEC.md`

Причина: в этой среде исходные вложения доступны для чтения/поиска, но большие документы возвращаются частями; создавать «якобы полный» файл из обрезанного текста нельзя.

### Правильный способ завершить миграцию
Когда локальная папка игры будет синхронизирована с репозиторием, Codex должен скопировать эти четыре существующих `.md` из локального проекта в `docs/systems/` без пересказа и без смыслового редактирования. После этого ChatGPT может проверить их на противоречия с новыми дополнениями и обновить MASTER_SPEC.
