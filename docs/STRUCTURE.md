# Структура базы знаний

Этот файл материализует каталоги, которые Git не умеет хранить пустыми. При появлении реальных документов служебные разделы можно дополнять, но назначение каталогов сохраняется.

## systems
Общие игровые механики и правила.

## world
Иерархическая база сущностей мира:
`hyperclusters → locations → objects/actions`, а также NPC, эффекты и квесты. Связи задаются стабильными ID, а не только вложенностью каталогов.

## content
Игровой текст отделён от правил: сцены, диалоги и описания могут ссылаться на ID сущностей мира.

## graphs
Визуальные Mermaid-представления. Не являются самостоятельным источником истины при конфликте с каноническими карточками.

## tasks
Очередь реализации. Статусы: backlog, ready, in_progress, review, done.

## templates
Единые шаблоны для новых сущностей и рабочих документов.
