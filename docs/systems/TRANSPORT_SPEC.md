# Транспорт и перемещение между гиперкластерами

Статус: утверждена базовая версия.

## 1. Гиперкластеры

Мир делится на крупные зоны — гиперкластеры: спальный район, университет, центр города и будущие зоны. Внутри гиперкластера игрок перемещается по обычным локациям; между гиперкластерами используется транспорт.

## 2. Автобусная остановка

В первой версии единственный междукластерный транспорт — автобус.

В спальном районе есть интерактивная автобусная остановка. При выборе открывается транспортный интерфейс со списком известных и доступных гиперкластеров.

Для каждого направления показывается временная стоимость поездки до подтверждения выбора.

Пример:
- Университет — N минут;
- Центр города — N минут.

## 3. Маршрут

Маршруты должны храниться как данные, а не быть зашиты в сценах.

Рекомендуемая сущность:
```python
{
  "from": "hc_residential_district",
  "to": "hc_university",
  "mode": "bus",
  "duration_minutes": DATA_VALUE
}
```

После подтверждения:
- продвигается единое игровое время;
- игрок переносится во входную транспортную точку целевого гиперкластера;
- отправляются события перемещения/входа в локацию;
- время поездки учитывается дедлайнами.

## 4. Будущее расширение

Архитектура сразу должна поддерживать `mode`, хотя в v1 реализуется только `bus`.

Будущие варианты:
- `walk` — медленнее, возможно с энергетической стоимостью;
- `taxi` — быстрее, но за деньги;
- другие виды транспорта.

Нельзя архитектурно приравнивать «переход между гиперкластерами» к автобусу навсегда.

## 5. Сюжетный дедлайн университета

Последний безопасный момент отправления 29 августа рассчитывается из:
`18:00 - travel_time - safety_margin`.

В сценах не хардкодить конкретное время последнего автобуса/отправления, если оно может быть вычислено из маршрута и дедлайна.
