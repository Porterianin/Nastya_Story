# Техническое задание: система характеристик Насти

## 1. Назначение документа

Документ определяет новую упрощённую систему характеристик для пересобираемой версии игры «Nastya Story».

Система должна:

- быть понятной игроку без изучения сложных формул;
- не содержать дублирующих характеристик;
- позволять предсказуемо рассчитывать условия действий и событий;
- поддерживать постепенное изменение личности Насти;
- учитывать одежду, профессиональные занятия, настроение и возбуждение;
- расширяться новыми навыками без изменения базового класса персонажа.

В этот документ не входят отношения с NPC, экономика, задания и общая система сюжетных флагов. Они будут описаны отдельными разделами технического задания. Здесь определены только флаги, непосредственно необходимые характеристикам.

## 2. Итоговый состав системы

### 2.1. Постоянные направления развития

1. Раскрепощённость.
2. Физическая форма.
3. Интеллект.

### 2.2. Расходуемый ресурс

4. Энергия.

### 2.3. Временные состояния

5. Настроение.
6. Возбуждение.

### 2.4. Приобретаемые навыки

Навыки не создаются заранее полным списком. Каждый навык появляется у Насти после знакомства с соответствующей деятельностью.

Примеры: официантка, йога, танцы, кулинария, медицина, работа с компьютером, фотография.

## 3. Энергия

### 3.1. Назначение

Энергия определяет, может ли Настя выполнить действие в текущий момент. Это очки действий, а не характеристика личности.

### 3.2. Диапазон

- Минимум: `0`.
- Максимум по умолчанию: `10`.
- Стартовое значение после полноценного сна: `10`.

Постоянное увеличение максимума не предусматривается. Баланс строится через стоимость действий и восстановление.

### 3.3. Примерная стоимость

| Тип действия | Стоимость энергии |
|---|---:|
| Перемещение внутри одной локации | 0 |
| Небольшое бытовое действие | 1 |
| Учёба, уборка, продолжительное общение | 2 |
| Тренировка | 3 |
| Рабочая смена | 4–5 |

### 3.4. Восстановление

- полноценный сон восстанавливает энергию полностью;
- короткий отдых восстанавливает ограниченное количество;
- еда восстанавливает количество, заданное конкретному блюду;
- ванна, душ и приятные занятия могут восстанавливать небольшое количество;
- результат всегда ограничивается максимальным значением.

### 3.5. Связь с физической формой

Физическая форма может уменьшать стоимость только тех действий, которые явно помечены как физически затратные.

Навык конкретной профессии или занятия не уменьшает расход энергии.

Минимальная стоимость физически затратного действия после всех модификаторов задаётся самим действием и обычно не может быть меньше `1`.

## 4. Раскрепощённость

### 4.1. Назначение

Раскрепощённость объединяет прежние понятия смелости, развращённости и доминантности. Она показывает, на какие поступки Настя в принципе готова, какие варианты диалога принимает и какую одежду согласна носить.

### 4.2. Видимые ступени

| Ранг | Код | Отображаемое название |
|---:|---|---|
| 0 | `modest` | Скромная |
| 1 | `curious` | Любопытная |
| 2 | `bold` | Смелая |
| 3 | `liberated` | Раскрепощённая |

Пятая ступень заранее не вводится. Она может быть добавлена только при появлении реального сюжетного содержания, которому недостаточно четырёх рангов.

### 4.3. Правила развития

- Игрок видит ранг, но не обязан видеть точное внутреннее количество прогресса.
- Повторение одного и того же простого действия не должно бесконечно повышать раскрепощённость.
- Значимый поступок обычно даёт прогресс только первый раз.
- Переход на новый ранг требует одновременно накопленного прогресса и сюжетного контрольного события.
- Раскрепощённость по умолчанию не уменьшается. Обратное изменение допускается только отдельным сюжетным решением.

Пример порогов для первоначальной балансировки:

| Переход | Минимальный прогресс | Дополнительное условие |
|---|---:|---|
| Скромная → Любопытная | 3 | Не менее одного значимого флага |
| Любопытная → Смелая | 8 | Не менее двух значимых флагов |
| Смелая → Раскрепощённая | 15 | Ключевое сюжетное событие |

Числа являются балансировочными и могут изменяться без изменения архитектуры.

### 4.4. Одежда

Каждая вещь может содержать:

```python
{
    "id": "short_dress",
    "required_openness_rank": 2,
    "tags": ["dress", "short", "revealing"]
}
```

Отсутствие элементов одежды описывается состоянием комплекта и тегами, например:

```python
["dress", "short", "no_panties"]
```

Проверка доступности одежды использует ранг раскрепощённости. Отдельные сюжетные флаги могут временно разрешать или запрещать конкретный вариант.

Реакция окружающих рассчитывается не только по рангу раскрепощённости, а по сочетанию:

- надетой одежды и её тегов;
- наличия или отсутствия нижнего белья;
- локации;
- присутствующих NPC;
- характера и взглядов NPC;
- сюжетных флагов;
- текущего возбуждения и настроения Насти, если это необходимо событию.

## 5. Физическая форма

### 5.1. Назначение

Физическая форма объединяет силу, выносливость, ловкость и гибкость. Отдельные характеристики для этих качеств не создаются.

### 5.2. Ступени

| Ранг | Код | Название |
|---:|---|---|
| 0 | `weak` | Слабая |
| 1 | `normal` | Обычная |
| 2 | `fit` | Подтянутая |
| 3 | `athletic` | Спортивная |
| 4 | `excellent` | Отличная |

### 5.3. Влияние

Физическая форма может:

- уменьшать расход энергии физических действий;
- открывать физически сложные действия и события;
- влиять на результат тренировок, спорта, танцев и физической работы;
- влиять на внешний вид тела и реакции NPC;
- ускорять развитие только тех приобретаемых навыков, для которых она назначена профильной характеристикой.

Физическая форма не влияет на умственные навыки и не применяется ко всем навыкам автоматически.

## 6. Интеллект

### 6.1. Назначение

Интеллект отражает общую подготовку, способность учиться, понимать сложные задачи и осваивать умственные профессии.

### 6.2. Ступени

| Ранг | Код | Название |
|---:|---|---|
| 0 | `unprepared` | Без подготовки |
| 1 | `basic` | Базовый уровень |
| 2 | `good` | Хорошая подготовка |
| 3 | `advanced` | Продвинутый уровень |
| 4 | `high` | Высокий уровень |

### 6.3. Влияние

Интеллект может:

- влиять на оценки и результат учёбы;
- открывать сложные умственные действия;
- давать дополнительные варианты диалога, связанные с пониманием ситуации;
- влиять на работу с информацией, техникой, медициной и компьютером;
- ускорять развитие только тех приобретаемых навыков, для которых он назначен профильной характеристикой.

Интеллект не влияет на физические навыки и не применяется ко всем навыкам автоматически.

## 7. Настроение

### 7.1. Ступени

| Значение | Код | Название |
|---:|---|---|
| -1 | `low` | Подавленное |
| 0 | `normal` | Нормальное |
| 1 | `good` | Приподнятое |

### 7.2. Правила

- Настроение не прокачивается и не имеет постоянного опыта.
- Оно изменяется событиями, отдыхом, общением и результатами действий.
- С течением времени состояние может возвращаться к нормальному.
- Настроение влияет на реплики, реакции и отдельные варианты действий.
- Настроение не заменяет энергию и возбуждение.

## 8. Возбуждение

### 8.1. Ступени

| Значение | Код | Название |
|---:|---|---|
| 0 | `calm` | Спокойна |
| 1 | `light` | Слегка возбуждена |
| 2 | `aroused` | Возбуждена |
| 3 | `strong` | Сильно возбуждена |

### 8.2. Влияние

Слегка возбуждена:

- доступны лёгкие флиртующие реакции;
- изменяются отдельные внутренние реплики;
- окружающие обычно не замечают состояние.

Возбуждена:

- открываются более смелые варианты;
- возможны штрафы к действиям, требующим длительной концентрации;
- внимательный или близкий NPC может заметить состояние.

Сильно возбуждена:

- рациональные и требующие концентрации действия могут быть ограничены;
- состояние может быть заметно окружающим;
- открываются наиболее откровенные реакции, если их допускает раскрепощённость;
- игроку всегда предоставляется хотя бы один доступный способ снизить возбуждение.

### 8.3. Изменение

Возбуждение может повышаться от эротического контента, флирта, прикосновений, фантазий и сюжетных ситуаций.

Возбуждение может снижаться от времени, сна, душа, переключения внимания, физических действий, уединения или интимной разрядки.

Одежда сама по себе не обязана повышать возбуждение. Учитывается контекст, присутствующие персонажи и ситуация.

### 8.4. Связь с раскрепощённостью

- Раскрепощённость определяет, на что Настя в принципе готова.
- Возбуждение определяет силу её текущего желания и импульсивности.
- Высокое возбуждение не должно навсегда обходить ограничения раскрепощённости.
- Отдельные конфликтные варианты могут появляться у скромной Насти при сильном возбуждении, но должны быть специально описаны событием.

## 9. Приобретаемые навыки

### 9.1. Общие правила

- Навык отсутствует, пока Настя не познакомилась с деятельностью.
- Навык развивается практикой, обучением и сюжетными событиями.
- Высокая базовая характеристика не создаёт профессиональный навык автоматически.
- Навык не уменьшает расход энергии.
- Навык влияет на качество, оплату, чаевые, вероятность ошибки, доступные профессиональные действия и специальные события.

### 9.2. Ступени

| Ранг | Код | Название |
|---:|---|---|
| 0 | `unlearned` | Навык отсутствует |
| 1 | `novice` | Новичок |
| 2 | `experienced` | Опытная |
| 3 | `professional` | Профессионал |

### 9.3. Профильная характеристика

Каждый навык обязан явно объявить одну профильную характеристику:

- `fitness` — для преимущественно физических навыков;
- `intellect` — для преимущественно умственных навыков;
- `openness` — только для навыков, где раскрепощённость действительно является условием освоения или исполнения.

Вторая характеристика допускается только тогда, когда обе объективно участвуют в конкретной деятельности. Она не добавляется для формального усложнения расчёта.

Пример определения:

```python
{
    "id": "waitress",
    "primary_attribute": "fitness",
    "secondary_attribute": None,
    "levels": 3
}
```

Для отдельных сложных действий внутри профессии может использоваться дополнительная проверка другой характеристики, не превращая её в постоянную характеристику всего навыка. Например, обычная работа официанткой зависит от физической формы, а запоминание большого заказа в специальном событии может отдельно проверять интеллект.

### 9.4. Разделение ответственности

Базовая характеристика отвечает за возможности Насти:

- физическая форма — насколько тяжело выполнить физическую работу;
- интеллект — насколько легко понять и освоить умственную деятельность;
- раскрепощённость — готова ли Настя участвовать в определённой деятельности.

Навык отвечает за качество конкретной деятельности:

- качество результата;
- размер профессиональной награды;
- вероятность ошибки;
- доступ к сложным рабочим операциям;
- специальные профессиональные события.

### 9.5. Пример: официантка

Профильная характеристика: физическая форма.

Физическая форма:

- изменяет расход энергии за смену;
- может определять доступность длинной или сложной смены.

Навык официантки:

- повышает чаевые и качество обслуживания;
- снижает вероятность профессиональных ошибок;
- открывает сложные столики, важных клиентов и специальные события;
- не уменьшает расход энергии.

Интеллект может проверяться только в отдельных ситуациях: сложный заказ, касса, конфликт в расчёте. Он не обязан быть второй постоянной характеристикой навыка официантки.

### 9.6. Пример: йога

Профильная характеристика: физическая форма.

Навык йоги:

- определяет доступные упражнения;
- влияет на качество выполнения;
- открывает занятия, мероприятия и возможность обучать других;
- не уменьшает расход энергии.

### 9.7. Пример: компьютер

Профильная характеристика: интеллект.

Навык работы с компьютером:

- определяет сложность доступных операций;
- влияет на скорость и качество результата;
- открывает новые виды работы и сюжетные действия.

Физическая форма и раскрепощённость на этот навык не влияют.

## 10. Предлагаемая структура данных

```python
player_state = {
    "energy": 10,
    "openness": {
        "rank": 0,
        "progress": 0,
        "milestones": set(),
    },
    "fitness": {
        "rank": 1,
        "progress": 0,
    },
    "intellect": {
        "rank": 1,
        "progress": 0,
    },
    "mood": 0,
    "arousal": 0,
    "skills": {},
}
```

Пример появившегося навыка:

```python
player_state["skills"]["waitress"] = {
    "rank": 1,
    "progress": 0,
}
```

Конкретная реализация может использовать классы вместо словарей, но смысловое разделение должно сохраниться.

## 11. Интерфейс изменения состояния

Сценарный код не должен напрямую присваивать значения полям. Используются единые функции или методы:

```python
change_energy(-2)
add_openness_progress(1, milestone="first_bold_outfit")
add_fitness_progress(1)
add_intellect_progress(1)
set_mood("good")
change_arousal(1)
add_skill_progress("waitress", 1)
```

Каждая функция обязана:

- проверять допустимые границы;
- корректно обрабатывать переход на новый ранг;
- отправлять единое игровое событие;
- при необходимости показывать уведомление;
- сохранять совместимость с сохранениями текущей версии новой архитектуры.

## 12. Удаляемые старые характеристики

При миграции не переносятся как самостоятельные характеристики:

- привлекательность;
- выносливость;
- здоровье, если для него не будет утверждена отдельная активная механика;
- прежний интеллект в числовой шкале `0–100`;
- развращённость;
- доминантность;
- старое настроение `0–100`;
- глобальный стресс;
- гигиена;
- отдельный навык фитнеса;
- заранее созданные медицина, кулинария, танцы и массаж;
- интимные размеры, опыт и травмы внутри общего класса характеристик.

Конкретные факты биографии и произошедших сцен при необходимости хранятся как сюжетные флаги и счётчики, а не как общие характеристики.

## 13. Критерии приёмки

- В игре отсутствуют дублирующие характеристики.
- Максимум энергии и все её изменения рассчитываются одним модулем.
- Физическая форма уменьшает стоимость только физических действий.
- Профессиональные навыки не уменьшают расход энергии.
- Каждый навык имеет ровно одну профильную характеристику или обоснованное исключение с двумя.
- Непрофильные характеристики не участвуют в расчёте навыка.
- Навыки появляются только после знакомства с деятельностью.
- Раскрепощённость отображается ступенью, а не числом.
- Повторение одного простого действия не позволяет бесконечно повышать раскрепощённость.
- Доступность одежды учитывает ранг раскрепощённости.
- Реакции на одежду могут учитывать теги комплекта, отсутствие белья, место и NPC.
- Настроение и возбуждение хранятся отдельно.
- При сильном возбуждении у игрока всегда остаётся доступный способ снизить его.
- Сценарные файлы изменяют характеристики только через единый программный интерфейс.
- Все переходы между ступенями проверяются автоматическими тестами или отладочным экраном.

## 14. Статус решения

Концепция характеристик утверждена как базовая версия технического задания. Балансировочные числа, названия отдельных ступеней и перечень будущих навыков могут уточняться без изменения архитектурных принципов этого документа.

## 15. Стартовые параметры новой игры

При создании новой игры состояние Насти инициализируется следующими значениями:

| Параметр | Стартовое значение |
|---|---|
| Энергия | `10/10` |
| Раскрепощённость | Скромная, ранг `0`, внутренний прогресс `0` |
| Физическая форма | Обычная, ранг `1`, внутренний прогресс `0` |

| Возбуждение | Спокойна, уровень `0` |
| Приобретённые навыки | Отсутствуют |

Стартовые значения создаются одной функцией инициализации состояния игрока. Пролог, интерфейс и отдельные сценарные метки не должны повторно присваивать их напрямую.

Новая игра должна создавать новый независимый объект состояния. Повторный запуск новой игры не должен сохранять характеристики, прогресс или приобретённые навыки из предыдущего прохождения.

После загрузки сохранения функция стартовой инициализации не вызывается и существующее состояние не перезаписывается.
