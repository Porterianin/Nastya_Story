# Временные эффекты в HUD

Статус: утверждена концепция.

## Назначение

Основной HUD не должен превращаться в набор постоянных шкал для каждого временного состояния. Краткосрочные игровые состояния показываются компактными значками эффектов.

## Поведение значка

- появляется только при активном эффекте;
- исчезает после завершения эффекта;
- имеет tooltip с названием и конкретным игровым последствием;
- поддерживает варианты severity, если состояние усиливается;
- не рассчитывает правила самостоятельно, а отображает готовое состояние игрового модуля.

## Первый обязательный эффект

`effect_hungry`.

При `hungry` значок сообщает, что Настя голодна и часть физических действий требует больше энергии.

При `very_hungry` должен использоваться более выраженный вариант/состояние значка и tooltip с дополнительными ограничениями.

## Будущее

Через ту же систему могут отображаться другие временные состояния, если они действительно требуют оперативного внимания игрока. Не создавать новую постоянную HUD-панель для каждого нового эффекта.

## Связь с UI visual spec

Значки должны соответствовать общей визуальной системе: цветные, единообразные, хорошо читаемые на разных фонах; tooltip использует общий компонент HUD/Tooltip.
