# Графы — карта раздела

Mermaid-графы — **производные представления** канонических карточек и спецификаций, а не отдельный источник истины.

- [`residential_district.mmd`](residential_district.mmd) — физическая/иерархическая структура стартового спального района.
- [`residential_navigation.mmd`](residential_navigation.mmd) — реальные, быстрые, закрытые и будущие маршруты игрока.

Если изменение канона затрагивает состав помещений, связи локаций, доступность маршрутов или точки переходов, соответствующий граф обновляется в том же цикле. При конфликте графа с канонической карточкой исправляется производное представление, если владелец не утвердил изменение самого канона.

Основные источники структуры: [`../world/hyperclusters/`](../world/hyperclusters/) и [`../world/locations/`](../world/locations/). Change-impact: [`../REPOSITORY_MAP.md`](../REPOSITORY_MAP.md).
