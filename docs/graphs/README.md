# Графы

Mermaid-графы мира, локаций, квестов и зависимостей. Это визуальные представления канонических карточек и спецификаций, а не отдельный источник истины.

## Обязательная синхронизация

Если изменение канона затрагивает структуру мира, состав помещений, связи локаций, доступность маршрутов или точки переходов, соответствующие графы должны обновляться в том же цикле изменений.

Минимальная проверка:

- `residential_district.mmd` — физическая/иерархическая структура стартового спального района;
- `residential_navigation.mmd` — реальные, быстрые, закрытые и будущие маршруты игрока.

Нельзя считать изменение локации завершённым, если карточка обновлена, а граф продолжает показывать старую структуру.

Для определения связанных файлов использовать `docs/REPOSITORY_MAP.md`.
