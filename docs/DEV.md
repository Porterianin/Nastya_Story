# DEV

## Требования
- Установленный Ren'Py SDK (версия 8.x или новее).

## Запуск
1. Открыть каталог репозитория в Ren'Py Launcher.
2. Выбрать проект и запустить `Launch Project`.

## Проверка статических label
- Скрипт `scripts/check_labels.py` ищет дублирующиеся label и неизвестные переходы.
- Запуск: `python scripts/check_labels.py game`.

## Структура
- `game/core` — системы (статы, навыки, деньги, события, квесты, разблокировки).
- `game/content` — локации, действия, события, персонажи.
- `game/ui` — стили и экраны HUD/панелей.
- `docs` — дизайн, сценарий, маршрут развития.
