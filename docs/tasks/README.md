# Задания Codex — карта раздела

Это очередь **реализации**, а не канон дизайна. Проектные решения сначала фиксируются в соответствующих `docs/systems/`, `docs/world/` или `docs/content/`, затем TASK ссылается на них.

Жизненный цикл:

`backlog → ready → in_progress → review → done`

- [`backlog/`](backlog/) — идея или незавершённое проектирование; не реализовывать.
- [`ready/`](ready/) — требования утверждены и готовы к реализации.
- [`in_progress/`](in_progress/) — текущая реализация.
- [`review/`](review/) — реализация завершена и ожидает проверки владельца.
- [`done/`](done/) — принято владельцем.
